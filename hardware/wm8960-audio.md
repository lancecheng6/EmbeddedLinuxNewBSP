# i.MX6ULL ↔ WM8960G Audio Interface (ATK-IMX6U)

**Device:** Wolfson/Cirrus WM8960G (= WM8960, 32-pin QFN 5×5×0.9mm)
**Board:** ATK-IMX6U (i.MX6ULL core board + ALPHA baseboard V2.4)

---

## 1. Device Identification

The board's codec is **WM8960G**, the RoHS/QFN ordering variant of the
**WM8960** (datasheet ordering info: `WM8960GEFL/V`, 32-pin QFN 5×5×0.9mm,
Pb-free, -40~85°C). Its 33 pins (32 + GND_PADDLE) match the WM8960 datasheet
PIN DESCRIPTION 100%.

Key features: 24-bit Σ-Δ ADC/DAC (SNR 98/94dB), stereo Class D speaker drivers
(>1W/8Ω), headphone amplifier (capless mode), MICBIAS + pseudo-differential
MIC, ALC/Limiter/Noise Gate, on-chip PLL, I2S interface, 2-wire (I2C,
addr `0x1A`) control.

## 2. SoC Interface (Verified)

| WM8960 Pin | Signal | J2 Pin | i.MX6ULL Ball | IOMUX (default / ALT / GPIO) |
|:---:|:---|:---:|:---|:---|
| 11 | MCLK | 20 | P14 | JTAG_TMS / SAI2_MCLK / GPIO1_IO11 |
| 12 | BCLK | 17 | N16 | JTAG_TDI / SAI2_TX_BCLK / GPIO1_IO13 |
| 13 | DACLRC | 18 | N15 | JTAG_TDO / SAI2_TX_SYNC / GPIO1_IO12 |
| 14 | DACDAT | 21 | N14 | JTAG_nTRST / SAI2_TX_DATA / GPIO1_IO15 |
| 16 | ADCDAT | 19 | M14 | JTAG_TCK / SAI2_RX_DATA / GPIO1_IO14 |
| 15 | ADCLRC/GPIO1 | **3** | P9 | SNVS_TAMPER4 / GPIO5_IO04 |
| 17 | SCLK | 33 | G17 | UART4_TXD / I2C1_SCL / GPIO1_IO28 |
| 18 | SDIN | 34 | G16 | UART4_RXD / I2C1_SDA / GPIO1_IO29 |

- **SAI2** uses the JTAG pins (the board has no JTAG debug port), routed via
  core-board connector J2 (pins 17-21) to the baseboard.
- **I2C1** uses the UART4_TXD/RXD pins (ALT = I2C1).
- **ADCLRC/GPIO1** is used as GPIO (AUD_INT, audio/headphone interrupt) with
  `ALRCGPIO=1` (DTS `wlf,shared-lrclk`): DACLRC then clocks both ADC and DAC.
- The WM8960 runs in **slave** mode; MCLK / BCLK / LRC are generated by SAI2.

## 5. Headphone Outputs (with shunt bypass filter)

| Pin | Series path | Shunt (to AGND) |
|:---:|:---|:---|
| HP_L (31) | C45 47µF → R54 0Ω → PHONE pin 2 | R26 10kΩ → C10 220pF |
| HP_R (29) | C46 47µF → R83 0Ω → PHONE pin 5 | R30 10kΩ → C91 220pF |

**Design analysis (impedance):**

| Frequency | 220pF reactance | Shunt branch | vs headphone 16–32Ω | Result |
|:---:|:---:|:---:|:---:|:---|
| 1 kHz | ≈723 kΩ | ≈733 kΩ | ≫ | audio goes to the headphone, no leakage to ground |
| MHz | near short | very low | — | EMI is bypassed to AGND (cable does not radiate) |

- **Series path**: C45/C46 are DC-blocking capacitors; only the AC audio
  (20 Hz–20 kHz) reaches the headphone.
- **Shunt path**: R26/R30 + C10/C91 form a high-frequency RC bypass to AGND.
  At 1 kHz the 220pF reactance is ~723 kΩ, so the branch (~733 kΩ) is far above
  the headphone impedance and does not load the signal. At RF/MHz frequencies
  the capacitor is nearly a short, pulling board noise/EMI to AGND.
- **Pop-click suppression**: R26/R30 also provide a DC bleed path for C45/C46
  when nothing is plugged in.

## 8. Verified Facts & Notes

1. **OUT3 = NC** (not connected to the speaker jack).
2. **AUD_INT = J2 Pin 3** (not pin 1; J2_1/J2_2 are DC5V).
3. **MAIN_MIC2P/N** = electret mic +/− (differential input), mic − grounded via **R48 (0Ω)**.
4. **MICBIAS resistors**: R49 = 680Ω, R47 = 47kΩ, R48 = 0Ω (three different
   values — do not mix them up).
5. **R26/C10 belong to HP_L**, **R30/C91 belong to HP_R** (shunt filters, not
   LINPUT3/speaker-jack parts).
6. **LINPUT3** connects only to C44 (LINE_INR) → LINE_IN pin 5 (no headphone-mic branch).
7. **SAI2 MCLK direction** for i.MX6UL is controlled by IOMUXC_GPR1
   (0x020E4004) bit20; the fsl-sai driver sets it automatically.
8. Linux playback verified: `aplay test.wav` → speaker sound
   (48 kHz/16-bit/stereo, card `atkwm8960`). See `docs/DevLog_20260801.md`.
