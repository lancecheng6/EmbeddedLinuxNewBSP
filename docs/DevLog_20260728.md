## 1. DTS Modifications (Device Tree)

### Final DTS Structure

```
Base: imx6ul-14x14-evk.dtsi (NXP EVK reference design)
  ├─ fec1 (ENET1) → ethphy0 (reg=2) → PHY2 (SR8201F, Reset GPIO5_IO07)
  ├─ fec2 (ENET2) → ethphy1 (reg=1) → PHY1 (SR8201F, Reset GPIO5_IO08)
  └─ Shared MDIO bus (GPIO1_IO06/IO07)
```

### Issues & Solutions

| # | Issue | Symptom | Root Cause | Fix |
|---|-------|---------|------------|-----|
| 1 | gpio-hog occupies reset GPIO | `fec: probe failed with error -EBUSY` | `&gpio5 { phy-reset-hog {...} }` claims GPIO5_IO07/IO08 at boot | Remove phy-reset-hog, let FEC driver control reset |
| 2 | spi-4 (bitbang SPI) uses same GPIO | Same `-EBUSY` | dtsi `spi-4` node uses GPIO5_IO07 (CS) and GPIO5_IO08 (enable) | `&{/spi-4} { status = "disabled"; };` |
| 3 | Wrong PHY type detected | PHY detected as KSZ8081 instead of SR8201F | dtsi uses Micrel ID `0022.1560` | Override: `&ethphy0/ethphy1 { compatible = "ethernet-phy-id0011.0140"; }` |

### Final DTS Source

```dts
// File: imx6ull-atk.dts (76 lines total)

#include "imx6ull.dtsi"
#include "imx6ul-14x14-evk.dtsi"
#include "imx6ull-pinfunc-snvs.h"

/ {
	model = "ATK-IMX6U Board";
	compatible = "fsl,imx6ull-14x14-evk", "fsl,imx6ull";
	chosen { stdout-path = &uart1; };
};

&uart1  { status = "okay"; };
&usdhc2 { status = "okay"; non-removable; };

&fec1 {
	phy-reset-gpios = <&gpio5 7 GPIO_ACTIVE_LOW>;
	phy-reset-duration = <200>;
};

&fec2 {
	phy-reset-gpios = <&gpio5 8 GPIO_ACTIVE_LOW>;
	phy-reset-duration = <200>;
};

&ethphy0 { compatible = "ethernet-phy-id0011.0140"; };
&ethphy1 { compatible = "ethernet-phy-id0011.0140"; };

&iomuxc_snvs {
	pinctrl_fec1_reset: fec1_resetgrp {
		fsl,pins = <MX6ULL_PAD_SNVS_TAMPER8__GPIO5_IO08 0x79>;
	};
	pinctrl_fec2_reset: fec2_resetgrp {
		fsl,pins = <MX6ULL_PAD_SNVS_TAMPER7__GPIO5_IO07 0x79>;
	};
};

/* Disable spi-4 which conflicts with PHY reset GPIOs */
&{/spi-4} {
	status = "disabled";
};
```

## 2. Rootfs Repair (BusyBox Symlinks)

The Buildroot-packaged rootfs.tar was missing critical BusyBox applet symlinks. These were fixed manually:

### Missing Symlinks

| Command | Path | Impact |
|---------|------|--------|
| `init` | `/sbin/init → /bin/busybox` | Kernel falls back to `/bin/sh`, no init system runs |
| `getty` | `/sbin/getty → /bin/busybox` | Cannot login via serial console |
| `ifup` | `/sbin/ifup → /bin/busybox` | Network cannot auto-start |
| `ip` | `/sbin/ip → /bin/busybox` | `ifup` needs `ip` internally for address configuration |
| `reboot` | `/sbin/reboot → /bin/busybox` | `reboot` command not found |
| `poweroff` | `/sbin/poweroff → /bin/busybox` | Cannot power off |
| `halt` | `/sbin/halt → /bin/busybox` | Cannot halt system |
| `swapon` | `/sbin/swapon → /bin/busybox` | Swap cannot be enabled |
| `syslogd` | `/sbin/syslogd → /bin/busybox` | System logging unavailable |
| `klogd` | `/sbin/klogd → /bin/busybox` | Kernel logging unavailable |
| `seedrng` | `/sbin/seedrng → /bin/busybox` | Random seed initialization fails |
| `head` | `/usr/bin/head → /bin/busybox` | Various script errors |
| `readlink` | `/usr/bin/readlink → /bin/busybox` | Dropbear init script errors |
| `xargs` | `/usr/bin/xargs → /bin/busybox` | sysctl script errors |
| `wc` | `/usr/bin/wc → /bin/busybox` | General use |
| `which` | `/usr/bin/which → /bin/busybox` | Find command paths |
| `seq` | `/usr/bin/seq → /bin/busybox` | General use |

### Fix (batch via SSH)

```bash
for cmd in swapon syslogd klogd reboot poweroff halt seedrng; do
  ln -sf /bin/busybox /sbin/$cmd
done
for cmd in head readlink xargs wc seq which; do
  ln -sf /bin/busybox /usr/bin/$cmd
done
```

## 3. SSH (Dropbear) Setup

### Buildroot Config Changes

| Option | Value | Description |
|--------|-------|-------------|
| `BR2_PACKAGE_DROPBEAR` | `=y` | Enable Dropbear SSH server |
| `BR2_PACKAGE_DROPBEAR_SMALL` | `=y` | Small build (bundled libtomcrypt) |
| `BR2_TARGET_GENERIC_HOSTNAME` | `="ATK"` | Hostname |
| `BR2_ROOTFS_OVERLAY` | `="board/atk-imx6u/rootfs-overlay"` | Rootfs overlay path |

Stored in `configs/atk_imx6u_min_defconfig`

### Rootfs Overlay Structure

```
board/atk-imx6u/rootfs-overlay/
├── etc/
│   ├── hostname                    → "ATK"
│   ├── network/interfaces          → Static IP config
│   └── dropbear/sshd_config        → Disable password auth
└── root/.ssh/authorized_keys       → RSA public key
```

### Network Configuration

```
Windows Ethernet (ASIX USB Ethernet): 192.168.1.1/24
Board eth0 (ENET1 / fec1):           192.168.1.100/24
Board eth1 (ENET2 / fec2):           192.168.1.101/24
```

### SSH Issues

| Issue | Cause | Fix |
|-------|-------|-----|
| `Connection timed out` | Windows Firewall blocking | `New-NetFirewallRule -Direction Outbound -RemotePort 22 -Action Allow` |
| `Connection timed out during banner exchange` | OpenSSH ED25519 key signing hangs | Use RSA key instead (`ssh-keygen -t rsa -b 2048`) |

### SSH Command

```powershell
ssh -i C:\Users\Lance\.ssh\atk_rsa_key root@192.168.1.100
```

## 4. DTB Flashing to eMMC — Transfer Methods Comparison

| Method | Result | Reason |
|--------|--------|--------|
| **Serial base64** (500-byte chunks) | ❌ Data corruption | Serial transmission drops data |
| **Serial base64** (100-byte chunks) | ❌ Decode failure | BusyBox `base64 -d` rejects embedded newlines |
| **Serial here-document** | ❌ Truncated input | Data string too long for serial buffer |
| **Serial printf hex escapes** | ❌ Shell stuck in continuation | Script too long for shell |
| **U-Boot USB + fatload/fatwrite** | ✅ Success | Load from USB stick, write via U-Boot |
| **SSH SCP** (after network is up) | ✅ Success | `scp file root@board:/tmp` — simplest |

## 5. Kernel Build (Enable USB)

### Kernel Config Changes

Added `usb.fragment`:

```
CONFIG_USB=y
CONFIG_USB_EHCI_HCD=y
CONFIG_USB_OHCI_HCD=y
CONFIG_USB_CHIPIDEA=y
CONFIG_USB_CHIPIDEA_UDC=y
CONFIG_USB_CHIPIDEA_HOST=y
CONFIG_USB_STORAGE=y
CONFIG_USB_HID=y
CONFIG_USB_OTG=y
```

### Build Steps

```bash
# Merge fragment
scripts/kconfig/merge_config.sh -m -O . .config usb.fragment
make ARCH=arm olddefconfig

# Build kernel + DTB
make ARCH=arm CROSS_COMPILE=.../arm-buildroot-linux-gnueabihf- zImage dtbs -j4
```

**Result:** zImage grew from 7.6MB to 8.2MB (~200KB of USB drivers)
