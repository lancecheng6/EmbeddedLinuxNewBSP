## 1. DTS 修改（Device Tree）

### 最終 DTS 結構

```
基底：imx6ul-14x14-evk.dtsi（NXP EVK 參考設計）
  ├─ fec1（ENET1）→ ethphy0（reg=2）→ PHY2（SR8201F，Reset GPIO5_IO07）
  ├─ fec2（ENET2）→ ethphy1（reg=1）→ PHY1（SR8201F，Reset GPIO5_IO08）
  └─ MDIO bus 共用（GPIO1_IO06/IO07）
```

### 問題與解決

| # | 問題 | 症狀 | 根因 | 解決 |
|---|------|------|------|------|
| 1 | gpio-hog 佔用 reset GPIO | `fec: probe failed with error -EBUSY` | `&gpio5 { phy-reset-hog {...} }` 在開機時佔用 GPIO5_IO07/IO08 | 刪除 phy-reset-hog，由 fec 驅動自行控制 reset |
| 2 | spi-4（bitbang SPI）佔用相同 GPIO | 同上 `-EBUSY` | dtsi 中的 spi-4 節點使用 GPIO5_IO07（CS）和 GPIO5_IO08（enable） | `&{/spi-4} { status = "disabled"; };` |
| 3 | PHY 型號不匹配 | PHY 被識別為 KSZ8081 而非 SR8201F | dtsi 使用 Micrel ID `0022.1560` | `&ethphy0/ethphy1 { compatible = "ethernet-phy-id0011.0140"; }` |

### 最終 DTS 原始碼

```dts
// 檔案：imx6ull-atk.dts（共 76 行）

#include "imx6ull.dtsi"
#include "imx6ul-14x14-evk.dtsi"
#include "imx6ull-pinfunc-snvs.h"

/ {
	model = "ATK-IMX6U Board";
	compatible = "fsl,imx6ull-14x14-evk", "fsl,imx6ull";
	chosen { stdout-path = &uart1; };
};

&uart1  { status = "okay"; };
&usdhc2 { status = "okay"; non-removable; };

&fec1 {
	phy-reset-gpios = <&gpio5 7 GPIO_ACTIVE_LOW>;
	phy-reset-duration = <200>;
};

&fec2 {
	phy-reset-gpios = <&gpio5 8 GPIO_ACTIVE_LOW>;
	phy-reset-duration = <200>;
};

&ethphy0 { compatible = "ethernet-phy-id0011.0140"; };
&ethphy1 { compatible = "ethernet-phy-id0011.0140"; };

&iomuxc_snvs {
	pinctrl_fec1_reset: fec1_resetgrp {
		fsl,pins = <MX6ULL_PAD_SNVS_TAMPER8__GPIO5_IO08 0x79>;
	};
	pinctrl_fec2_reset: fec2_resetgrp {
		fsl,pins = <MX6ULL_PAD_SNVS_TAMPER7__GPIO5_IO07 0x79>;
	};
};

/* 關閉 spi-4，它佔用了 PHY reset 用的 GPIO5_IO07/IO08 */
&{/spi-4} {
	status = "disabled";
};
```

## 2. rootfs 修復（BusyBox Symlink）

由於 Buildroot 打包 rootfs.tar 時 symlink 未被正確建立，需手動補上：

### 遺失的 symlink 一覽

| 指令 | 路徑 | 影響 |
|------|------|------|
| `init` | `/sbin/init → /bin/busybox` | 核心找不到 init，直接跑 `/bin/sh`，無正常初始化流程 |
| `getty` | `/sbin/getty → /bin/busybox` | Serial console 無法登入 |
| `ifup` | `/sbin/ifup → /bin/busybox` | 網路無法自動啟用 |
| `ip` | `/sbin/ip → /bin/busybox` | `ifup` 內部使用 `ip`，無法自動設定 IP |
| `reboot` | `/sbin/reboot → /bin/busybox` | `reboot` 指令不存在 |
| `poweroff` | `/sbin/poweroff → /bin/busybox` | 無法關機 |
| `halt` | `/sbin/halt → /bin/busybox` | 無法停止系統 |
| `swapon` | `/sbin/swapon → /bin/busybox` | swap 無法啟用 |
| `syslogd` | `/sbin/syslogd → /bin/busybox` | 系統日誌無法記錄 |
| `klogd` | `/sbin/klogd → /bin/busybox` | 核心日誌無法記錄 |
| `seedrng` | `/sbin/seedrng → /bin/busybox` | 隨機種子初始化失敗 |
| `head` | `/usr/bin/head → /bin/busybox` | 各種 shell script 錯誤 |
| `readlink` | `/usr/bin/readlink → /bin/busybox` | Dropbear 啟動腳本錯誤 |
| `xargs` | `/usr/bin/xargs → /bin/busybox` | sysctl 腳本錯誤 |
| `wc` | `/usr/bin/wc → /bin/busybox` | 一般使用 |
| `which` | `/usr/bin/which → /bin/busybox` | 查詢指令路徑 |
| `seq` | `/usr/bin/seq → /bin/busybox` | 一般使用 |

### 解決方式

透過 SSH 批次建立 symlink：

```bash
for cmd in swapon syslogd klogd reboot poweroff halt seedrng; do
  ln -sf /bin/busybox /sbin/$cmd
done
for cmd in head readlink xargs wc seq which; do
  ln -sf /bin/busybox /usr/bin/$cmd
done
```

## 3. SSH（Dropbear）安裝

### Buildroot 設定變更

| 選項 | 設定值 | 說明 |
|------|--------|------|
| `BR2_PACKAGE_DROPBEAR` | `=y` | 啟用 Dropbear SSH server |
| `BR2_PACKAGE_DROPBEAR_SMALL` | `=y` | 使用精簡版本（內建 libtomcrypt） |
| `BR2_TARGET_GENERIC_HOSTNAME` | `="ATK"` | 主機名稱 |
| `BR2_ROOTFS_OVERLAY` | `="board/atk-imx6u/rootfs-overlay"` | rootfs overlay 路徑 |

儲存在 `configs/atk_imx6u_min_defconfig`

### rootfs overlay 結構

```
board/atk-imx6u/rootfs-overlay/
├── etc/
│   ├── hostname                    → "ATK"
│   ├── network/interfaces          → 靜態 IP 設定
│   └── dropbear/sshd_config        → 關閉密碼登入
└── root/.ssh/authorized_keys       → RSA 公鑰
```

### 網路設定

```
Windows 乙太網路（ASIX USB Ethernet）：192.168.1.1/24
Board eth0（ENET1 / fec1）：        192.168.1.100/24
Board eth1（ENET2 / fec2）：        192.168.1.101/24
```

### SSH 連線問題

| 問題 | 原因 | 解決 |
|------|------|------|
| `Connection timed out` | Windows 防火牆阻擋 | `New-NetFirewallRule -Direction Outbound -RemotePort 22 -Action Allow` |
| `Connection timed out during banner exchange` | OpenSSH ED25519 金鑰簽章卡住 | 改用 RSA 金鑰（`ssh-keygen -t rsa -b 2048`） |

### SSH 連線指令

```powershell
ssh -i C:\Users\Lance\.ssh\atk_rsa_key root@192.168.1.100
```

## 4. DTB 寫入 eMMC — 傳輸方式比較

嘗試了多種方式把 DTB 寫入 boot 分割區：

| 方式 | 結果 | 原因 |
|------|------|------|
| **Serial base64**（500-byte chunks） | ❌ 資料失真 | 串列傳輸掉資料 |
| **Serial base64**（100-byte chunks） | ❌ `base64 -d` 不接受換行 | BusyBox base64 限制 |
| **Serial here-document** | ❌ truncated input | 字串太長被截斷 |
| **Serial printf hex escapes** | ❌ shell continuation 卡住 | 腳本太長 |
| **U-Boot USB + fatload/fatwrite** | ✅ 成功 | 從隨身碟載入後透過 U-Boot 寫入 |
| **SSH SCP**（網路通後） | ✅ 成功 | `scp file root@board:/tmp` 最直接 |

## 5. 核心編譯（啟用 USB）

### 核心配置變更

加入 `usb.fragment`：

```
CONFIG_USB=y
CONFIG_USB_EHCI_HCD=y
CONFIG_USB_OHCI_HCD=y
CONFIG_USB_CHIPIDEA=y
CONFIG_USB_CHIPIDEA_UDC=y
CONFIG_USB_CHIPIDEA_HOST=y
CONFIG_USB_STORAGE=y
CONFIG_USB_HID=y
CONFIG_USB_OTG=y
```

### 編譯流程

```bash
# 合併 fragment
scripts/kconfig/merge_config.sh -m -O . .config usb.fragment
make ARCH=arm olddefconfig

# 編譯核心與 DTB
make ARCH=arm CROSS_COMPILE=.../arm-buildroot-linux-gnueabihf- zImage dtbs -j4
```

**結果：** zImage 從 7.6MB 增加到 8.2MB（約 200KB 的 USB 驅動）
