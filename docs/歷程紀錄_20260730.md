## 3. U-Boot DCD（imximage.cfg）

### 檔案位置

`board/freescale/mx6ullevk/imximage.cfg`

路徑定義在 board 的 Kconfig 中：
```kconfig
config IMX_CONFIG
	default "board/freescale/mx6ullevk/imximage.cfg"
```

### 確認：PMIC 與 DDR 完全獨立

`CONFIG_DM_PMIC` 在目前 U-Boot 中**未啟用**。修改 `imximage.cfg` 只影響 Boot ROM 階段的 DDR 初始化，不影響 PMIC 或其他週邊。

### DCD 暫存器對照

| 偏移 | 暫存器 | 用途 |
|------|--------|------|
| 0x000C | MDCFG0 | tRFC, tXPDLL, tXP, tXS |
| 0x0010 | MDCFG1 | tRAS, tRC, tRCD, tRP, tWR |
| 0x0014 | MDCFG2 | tFAW, tRRD, tWTR, tRTP |
| 0x0020 | MDREF | 刷新率（tREFI） |

### MRS 指令編碼 — 關鍵學習

所有 DDR3 MR 寫入都透過同一個暫存器（`0x021B001C`），**最後一個半位元組（nibble）決定目標 MR**：

```
...2 → MR2（CWL, Dynamic ODT）
...3 → MR3（Multi-Purpose）
...1 → MR1（DLL, ODT, Driver Impedance）
...0 → MR0（CL, BL, DLL Reset）
```

NXP 原版 `imximage.cfg` 共用 5 筆指令完整涵蓋所有 MR：

```
0x02008032  → MR2
0x00008033  → MR3
0x00048031  → MR1
0x15208030  → MR0
0x04008040  → ZQ Calibration
```
