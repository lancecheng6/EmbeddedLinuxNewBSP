# Day 6 — WM8960 音效晶片研究與 Linux 播放實現（2026-08-01）

**目標：** 研究 ATK-IMX6U 板載 WM8960G 音效晶片（型號確認、SoC 介面、周邊電路），並完整實現 Linux 音訊播放（喇叭輸出）。

---

## 1. WM8960 晶片研究

### 1.1 型號確認

板載 **WM8960G** = **WM8960** 的 RoHS/QFN 訂購版本（datasheet 訂購型號 `WM8960GEFL/V`，32-pin QFN 5×5×0.9mm、無鉛、-40~85°C）。33 腳（32 + GND_PADDLE）與 WM8960 datasheet PIN DESCRIPTION **100% 一致**。

主要特色：24-bit Σ-Δ ADC/DAC（SNR 98/94dB）、立體聲 Class D 喇叭驅動（>1W/8Ω）、耳機放大器（Capless）、MICBIAS + 偽差分麥克風、ALC/Limiter/Noise Gate、內建 PLL、I2S/左對齊介面、2-wire（I2C，位址 `0x1A`）控制介面。

### 1.2 SoC 介面（已確認）

| WM8960 腳位 | 信號 | J2 Pin | i.MX6ULL Ball | IOMUX（預設 / ALT / GPIO）|
|:---:|:---|:---:|:---|:---|
| 11 | MCLK | 20 | P14 | JTAG_TMS / SAI2_MCLK / GPIO1_IO11 |
| 12 | BCLK | 17 | N16 | JTAG_TDI / SAI2_TX_BCLK / GPIO1_IO13 |
| 13 | DACLRC | 18 | N15 | JTAG_TDO / SAI2_TX_SYNC / GPIO1_IO12 |
| 14 | DACDAT | 21 | N14 | JTAG_nTRST / SAI2_TX_DATA / GPIO1_IO15 |
| 16 | ADCDAT | 19 | M14 | JTAG_TCK / SAI2_RX_DATA / GPIO1_IO14 |
| 15 | ADCLRC/GPIO1 | **3** | P9 | SNVS_TAMPER4 / GPIO5_IO04 |
| 17 | SCLK | 33 | G17 | UART4_TXD / I2C1_SCL / GPIO1_IO28 |
| 18 | SDIN | 34 | G16 | UART4_RXD / I2C1_SDA / GPIO1_IO29 |

- **SAI2** 使用 JTAG 腳位複用（本板無 JTAG 調試口），經核心板連接器 J2 送到底板。
- **I2C1** 使用 UART4_TXD/RXD 腳位複用。
- **ADCLRC/GPIO1** 作為 GPIO（AUD_INT，耳機/音訊中斷），`ALRCGPIO=1`（DTS `wlf,shared-lrclk`）：DACLRC 同時驅動 ADC 與 DAC。
- WM8960 為 **Slave** 模式；MCLK/BCLK/LRC 全由 SAI2 提供。

### 1.3 周邊電路（已確認）

**偏壓與參考**

| 元件 | 值 | 連接 |
|:---:|:---:|:---|
| R49 | 680 Ω | MICBIAS 串聯/限流 → 駐極體麥克風正端 |
| R47 | 47 kΩ | MICBIAS 偏壓電阻 → 麥克風 |
| R48 | 0 Ω | 麥克風負極（MAIN_MIC2N）→ AGND |
| C33 | 10 µF | MICBIAS 去耦 → AGND |
| C34 | 220 pF | 麥克風信號濾波 |
| C32 | 10 µF | VMID 去耦 → AGND |

**音訊輸入**

| 腳位 | 電路 | 連接 |
|:---:|:---|:---|
| LINPUT2 (3) | C40 1µF | MAIN_MIC2P（麥克風正）|
| LINPUT1 (4) | C41 1µF | MAIN_MIC2N（麥克風負，+ R48→AGND）|
| RINPUT2 (6) | C42 1µF（LINE_INL）| LINE_IN 座 pin 2 |
| LINPUT3 (2) | C44 1µF（LINE_INR）| LINE_IN 座 pin 5 |
| RINPUT1 (5) | C43 1µF | LINE_IN pin 6（偽差分參考，R52 DNP）|
| RINPUT3 (7) | HP_JD | PHONE 座 pin 6 + R53 24k→VCC3.3A + R52 DNP |

**耳機輸出**（含並聯旁路濾波設計）

| 腳位 | 串聯路徑 | 並聯（→AGND）|
|:---:|:---|:---|
| HP_L (31) | C45 47µF → R54 0Ω → PHONE pin 2 | R26 10k → C10 220pF |
| HP_R (29) | C46 47µF → R83 0Ω → PHONE pin 5 | R30 10k → C91 220pF |

*設計分析：* 1kHz 時 220pF 容抗 ≈723kΩ → 旁路支路 ≈733kΩ 遠大於耳機 16–32Ω → 音訊不洩漏到地；MHz 級容抗近短路 → EMI 旁路到 AGND（避免耳機線當天線）。R26/R30 同時在未插耳機時為 C45/C46 提供直流洩放路徑（抑制 Pop-Click）。

**喇叭輸出**（Class D BTL）

| 腳位 | 連接 |
|:---:|:---|
| SPK_RP (22) / SPK_RN (19) | → SPKR 座（右喇叭，BTL）|
| SPK_LP (25) / SPK_LN (23) | → SPKL 座（左喇叭，BTL）|

**電源**

| 腳位 | 來源 | 狀態 |

## 2. 驅動實現

### 2.1 kernel 配置（`linux-imx/audio.fragment`）

```kconfig
CONFIG_SOUND=y
CONFIG_SND=y
CONFIG_SND_SOC=y
CONFIG_SND_IMX_SOC=y
CONFIG_SND_SOC_FSL_SAI=y
CONFIG_SND_SOC_FSL_ASOC_CARD=y
CONFIG_SND_SOC_FSL_ASRC=y
CONFIG_SND_SOC_WM8960=y
CONFIG_IMX_SDMA=y
CONFIG_EXTRA_FIRMWARE="imx/sdma/sdma-imx6q.bin"
CONFIG_EXTRA_FIRMWARE_DIR="/lib/firmware"
```

以 `scripts/kconfig/merge_config.sh -m -O . .config audio.fragment` 套用（不動 GitHubUpload 的 defconfig/fragment）。

**SDMA 必須內建 + firmware 內嵌的原因：**
- SAI2/ASRC 使用 `&sdma` DMA 通道；`CONFIG_IMX_SDMA=m` 時模組永遠無法在音訊設備 probe 前載入 → `-EPROBE_DEFER` 連鎖。
- SDMA firmware（`sdma-imx6q.bin`）無法從 rootfs 載入：SDMA probe（~0.7s）早於 mmcblk1p2 掛載（~3s）。用 `CONFIG_EXTRA_FIRMWARE` 內嵌解決（開機 log：`firmware found, loaded 3.5`）。

### 2.2 Device Tree（`imx6ull-atk.dts`，linux-imx 版）

- `sound` 節點：compatible `fsl,imx6ul-evk-wm8960`, `fsl,imx-audio-wm8960`（machine driver = fsl-asoc-card）、`audio-cpu = <&sai2>`、`audio-codec = <&codec_atk>`、`audio-asrc = <&asrc>`、`hp-det-gpio = <&gpio5 4 0>`、`audio-routing`（官方 widget 名）。
- `&sai2`：pinctrl（JTAG 5 腳，`0x17088/0x11088`）+ assigned-clocks（PLL4_AUDIO_DIV → SAI2 = **12.288MHz** = 256fs@48k）+ `fsl,sai-mclk-direction-output` + `status = "okay"`。
- `&i2c1`：pinctrl（UART4 兩腳）+ `codec_atk: wm8960@1a`（`wlf,wm8960`、reg `0x1a`、clocks = IMX6UL_CLK_SAI2、`wlf,shared-lrclk`、`wlf,hp-cfg = <3 2 3>`、`wlf,gpio-cfg = <1 3>`）+ okay。
- `&asrc`：`status = "okay"`。
- 注意：NXP dtsi 已有 `codec` 標籤在 **i2c2**；本板 WM8960 在 **i2c1** → 使用獨立 `codec_atk` 標籤並禁用官方 `&codec`。

### 2.3 rootfs（Buildroot）

- `BR2_PACKAGE_ALSA_UTILS=y` + `BR2_PACKAGE_ALSA_UTILS_APLAY=y` + `BR2_PACKAGE_ALSA_UTILS_AMIXER=y`（ALSA_LIB 自動 select）。
- **mixer 開機自動恢復**：連結 `S60alsa-state` → `/etc/init.d/alsa-state` + `alsactl -f /var/lib/alsa/asound.state store`（重開機保留 mixer 狀態；本 rootfs 的 /var 持久）。

## 3. 除錯歷程

| 問題 | 根因 | 解決 |
|------|------|------|
| rootfs init 失敗（卡 shell）| 覆蓋式 `tar xf` 遺失 busybox symlink（`/sbin/init`、`/sbin/getty` 等）| `busybox --install -s /sbin`（含 /bin、/usr/sbin、/usr/bin）+ `ln -sf /bin/busybox /sbin/init` |
| sysvinit 讀 busybox inittab 卡住 | rootfs 是 busybox init 格式但 `/sbin/init` 誤指 sysvinit | 救援開機：U-Boot `bootargs ... init=/bin/busybox init`；修好 symlink 後正常開機 |
| `sdma or sdma firmware not ready` | SDMA=m 從未載入；rootfs 掛載晚於 probe | `CONFIG_IMX_SDMA=y` + `CONFIG_EXTRA_FIRMWARE`（內嵌）|
| `snd_soc_register_card failed` | audio-routing 自訂 widget 名（`Mic`、`Line In`）不存在 | 改用官方名：`Mic Jack`、`AMIC`、`Headphone Jack`、`Ext Spk` |
| 無聲（有 sound card）| `Left/Right Output Mixer PCM Playback Switch`（numid 52/55）未開 | `amixer cset numid=52 on; amixer cset numid=55 on` |
| 無聲（mixer 已開）| SAI2_MCLK 方向未設 → codec 無 SYSCLK | 實驗確認 **IOMUXC_GPR1（0x020E4004）bit20** 控制 SAI2 MCLK 方向；原版 fsl-sai 驅動（偏移 0x04）自動設定 |
| aplay 卡住（`write error: Interrupted system call`）| 播放被打斷（timeout / Ctrl-C）| 正常現象；Ctrl-C 恢復 shell |

## 4. 播放驗證

```
$ aplay -l
**** List of PLAYBACK Hardware Devices ****
card 0: atkwm8960 [atk-wm8960], device 0: HiFi wm8960-hifi-0
  Subdevices: 1/1
  Subdevice #0: subdevice #0
card 0: atkwm8960 [atk-wm8960], device 1: HiFi-ASRC-FE (*)

$ amixer cset numid=52 on    # Left Output Mixer PCM
$ amixer cset numid=55 on    # Right Output Mixer PCM
$ amixer sset 'Speaker' 15%

$ aplay /root/test.wav
Playing WAVE '/root/test.wav' : Signed 16 bit Little Endian,
                                Rate 48000 Hz, Stereo
→ 喇叭有聲 ✅
```

mixer 狀態以 `alsactl store` 保存、`S60alsa-state` 開機恢復 → 重開機後直接 `aplay test.wav` 即可播放。

## 5. 關鍵學習

1. **WM8960 無聲排查順序**：sound card 註冊 → Output Mixer PCM 開關 → MCLK（GPR1 方向）→ 音量。
2. **i.MX6UL SAI2 MCLK 方向** = IOMUXC_GPR1（0x020E4004）bit20；fsl-sai 驅動自動設定——不要「修正」寄存器偏移。
3. **SDMA firmware 載入時序**：SDMA probe 早於 rootfs 掛載 → 用 `CONFIG_EXTRA_FIRMWARE` 內嵌。
4. **busybox rootfs 的 symlink**：覆蓋式 tar 部署會悄悄遺失 symlink；`busybox --install -s <dir>` 一次補齊所有 applet。
5. **NXP `imx6ull-9x9-evk.dts` 是 WM8960 最佳參考**——其 SAI2（JTAG 複用）與 I2C1（UART4 複用）接線與 ATK-IMX6U 完全一致。
6. **WM8960 耳機旁路濾波**（R26/C10、R30/C91）：並聯到 AGND 濾 EMI；10k 電阻同時洩放直流防 Pop-Click。
