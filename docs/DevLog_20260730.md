## 3. U-Boot DCD (imximage.cfg)

### File Location

`board/freescale/mx6ullevk/imximage.cfg`

This path is defined in the board's Kconfig:
```kconfig
config IMX_CONFIG
	default "board/freescale/mx6ullevk/imximage.cfg"
```

### Verified: PMIC is Independent

`CONFIG_DM_PMIC` is **not set** in the current U-Boot .config. Modifying `imximage.cfg` only affects the DDR initialization DCD data, not PMIC or other peripherals.

### DCD Register Map

| Offset | Register | Purpose |
|--------|----------|---------|
| 0x000C | MDCFG0 | tRFC, tXPDLL, tXP, tXS |
| 0x0010 | MDCFG1 | tRAS, tRC, tRCD, tRP, tWR |
| 0x0014 | MDCFG2 | tFAW, tRRD, tWTR, tRTP |
| 0x0020 | MDREF | Refresh rate (tREFI) |

### MRS (Mode Register Set) via MDSCR

All DDR3 MR writes go through the same register (`0x021B001C`). The **lower nibble** of the MDSCR value selects the target register:

```
...2 → MR2 (CWL, Dynamic ODT)
...3 → MR3 (Multi-Purpose)
...1 → MR1 (DLL, ODT, Driver Impedance)
...0 → MR0 (CL, BL, DLL Reset)
```

### Key Learning

The NXP reference `imximage.cfg` correctly includes all four MR writes in a 5-command sequence:
```
0x02008032  → MR2
0x00008033  → MR3
0x00048031  → MR1
0x15208030  → MR0
0x04008040  → ZQ Calibration
```
