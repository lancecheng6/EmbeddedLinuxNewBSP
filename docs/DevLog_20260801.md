# Day 6 — WM8960 Audio Codec Study & Linux Playback (2026-08-01)

**Objective:** Study the WM8960G audio codec on the ATK-IMX6U (device
identification, SoC interface, peripheral circuits), then enable and verify

## 1. WM8960 Codec Study

### 1.1 Device Identification

The board uses **WM8960G**, which is the RoHS/QFN ordering variant of the
**WM8960** (datasheet ordering info: `WM8960GEFL/V`, 32-pin QFN 5×5×0.9mm,
Pb-free, -40~85°C). Its 33 pins (32 + GND_PADDLE) match the WM8960 datasheet
PIN DESCRIPTION 100%.

Key features: 24-bit Σ-Δ ADC/DAC (SNR 98/94dB), stereo Class D speaker drivers
(>1W/8Ω), headphone amplifier (capless mode), MICBIAS + pseudo-differential
MIC, ALC/Limiter/Noise Gate, on-chip PLL, I2S/left-justified interface and a
2-wire (I2C, addr `0x1A`) control interface.

### 1.2 SoC Interface (Verified)

| WM8960 Pin | Signal | J2 Pin | i.MX6ULL Ball | IOMUX (default / ALT / GPIO) |
|:---:|:---|:---:|:---|:---|
| 11 | MCLK | 20 | P14 | JTAG_TMS / SAI2_MCLK / GPIO1_IO11 |
| 12 | BCLK | 17 | N16 | JTAG_TDI / SAI2_TX_BCLK / GPIO1_IO13 |
| 13 | DACLRC | 18 | N15 | JTAG_TDO / SAI2_TX_SYNC / GPIO1_IO12 |
| 14 | DACDAT | 21 | N14 | JTAG_nTRST / SAI2_TX_DATA / GPIO1_IO15 |
| 16 | ADCDAT | 19 | M14 | JTAG_TCK / SAI2_RX_DATA / GPIO1_IO14 |
| 15 | ADCLRC/GPIO1 | **3** | P9 | SNVS_TAMPER4 / GPIO5_IO04 |
| 17 | SCLK | 33 | G17 | UART4_TXD / I2C1_SCL / GPIO1_IO28 |
| 18 | SDIN | 34 | G16 | UART4_RXD / I2C1_SDA / GPIO1_IO29 |

- **SAI2** uses the JTAG pins (no JTAG debug port on this board), routed
  through core-board connector J2 to the baseboard.
- **I2C1** uses the UART4_TXD/RXD pins (ALT = I2C1).
- **ADCLRC/GPIO1** is used as GPIO (AUD_INT, headphone/audio interrupt) with
  `ALRCGPIO=1` (DTS `wlf,shared-lrclk`): DACLRC then clocks both ADC and DAC.
- WM8960 runs in **slave** mode; MCLK/BCLK/LRC are all generated by SAI2.

### 1.3 Peripheral Circuits (Verified)

**Bias & Reference**

| Item | Value | Connection |
|:---:|:---:|:---|
| R49 | 680 Ω | MICBIAS series/limit → electret mic + |
| R47 | 47 kΩ | MICBIAS bias resistor → mic |
| R48 | 0 Ω | mic − (MAIN_MIC2N) → AGND |
| C33 | 10 µF | MICBIAS decoupling → AGND |
| C34 | 220 pF | mic signal filter |
| C32 | 10 µF | VMID decoupling → AGND |

**Audio Inputs**

| Pin | Circuit | Connection |
|:---:|:---|:---|
| LINPUT2 (3) | C40 1µF | MAIN_MIC2P (mic +) |
| LINPUT1 (4) | C41 1µF | MAIN_MIC2N (mic −, + R48→AGND) |
| RINPUT2 (6) | C42 1µF (LINE_INL) | LINE_IN jack pin 2 |
| LINPUT3 (2) | C44 1µF (LINE_INR) | LINE_IN jack pin 5 |
| RINPUT1 (5) | C43 1µF | LINE_IN pin 6 (pseudo-diff ref, R52 DNP) |
| RINPUT3 (7) | HP_JD | PHONE jack pin 6 + R53 24k→VCC3.3A + R52 DNP |

**Headphone Outputs** (with shunt bypass filter design)

| Pin | Series path | Shunt (to AGND) |
|:---:|:---|:---|
| HP_L (31) | C45 47µF → R54 0Ω → PHONE pin 2 | R26 10k → C10 220pF |
| HP_R (29) | C46 47µF → R83 0Ω → PHONE pin 5 | R30 10k → C91 220pF |

*Design analysis:* at 1 kHz a 220pF cap has ≈723kΩ reactance → the shunt branch
(≈733kΩ) is far above the 16–32Ω headphone, so no audio leaks to ground; at
MHz frequencies the cap is nearly a short, so EMI is bypassed to AGND (keeps
the headphone cable from acting as an antenna). R26/R30 also provide a DC bleed
path for C45/C46 when nothing is plugged in (pop-click suppression).

**Speaker Outputs** (Class D BTL)

| Pin | Connection |
|:---:|:---|
| SPK_RP (22) / SPK_RN (19) | → SPKR jack (right speaker, BTL) |
| SPK_LP (25) / SPK_LN (23) | → SPKL jack (left speaker, BTL) |

**Power**

| Pin | Source | Status |
|:---:|:---|:---:|
| AVDD (32) | VCC3.3A (VCC_3V3 → L7) | ✅ 3.3V |
| DCVDD (8) / DBVDD (10) | 3.3V | ✅ |
| SPKVDD1/2 (26/21) | **VCC_5V** (L8 ferrite, both pins tied) | ✅ 5V |
| OUT3 (30) | **NC** (unused) | — |

## 2. Kernel Audio Enablement

### 2.1 Kernel Config (`linux-imx/audio.fragment`)

```kconfig
CONFIG_SOUND=y
CONFIG_SND=y
CONFIG_SND_SOC=y
CONFIG_SND_IMX_SOC=y
CONFIG_SND_SOC_FSL_SAI=y
CONFIG_SND_SOC_FSL_ASOC_CARD=y
CONFIG_SND_SOC_FSL_ASRC=y
CONFIG_SND_SOC_WM8960=y
CONFIG_IMX_SDMA=y
CONFIG_EXTRA_FIRMWARE="imx/sdma/sdma-imx6q.bin"
CONFIG_EXTRA_FIRMWARE_DIR="/lib/firmware"
```

Applied with `scripts/kconfig/merge_config.sh -m -O . .config audio.fragment`
(the GitHubUpload defconfig/fragments are untouched).

**Why SDMA must be built-in + firmware embedded:**
- SAI2 and ASRC use `&sdma` DMA channels; with `CONFIG_IMX_SDMA=m` the module
  is never loaded before the sound devices probe → `-EPROBE_DEFER` chain.
- SDMA firmware (`sdma-imx6q.bin`) cannot be loaded from rootfs because the
  SDMA probe (~0.7s) runs before mmcblk1p2 mounts (~3s). Embedding via
  `CONFIG_EXTRA_FIRMWARE` fixes it (boot log: `firmware found, loaded 3.5`).

### 2.2 Device Tree (`imx6ull-atk.dts`, linux-imx)

- `sound` node: compatible `fsl,imx6ul-evk-wm8960`, `fsl,imx-audio-wm8960`
  (machine driver = fsl-asoc-card), `audio-cpu = <&sai2>`,
  `audio-codec = <&codec_atk>`, `audio-asrc = <&asrc>`,
  `hp-det-gpio = <&gpio5 4 0>`, `audio-routing` (official widget names).
- `&sai2`: pinctrl (JTAG 5 pins, `0x17088/0x11088`) +
  assigned-clocks (PLL4_AUDIO_DIV → SAI2 = **12.288MHz** = 256fs@48k) +
  `fsl,sai-mclk-direction-output` + `status = "okay"`.
- `&i2c1`: pinctrl (UART4 2 pins) + `codec_atk: wm8960@1a`
  (`wlf,wm8960`, reg `0x1a`, clocks = IMX6UL_CLK_SAI2,
  `wlf,shared-lrclk`, `wlf,hp-cfg = <3 2 3>`, `wlf,gpio-cfg = <1 3>`) + okay.
- `&asrc`: `status = "okay"`.
- Note: the NXP dtsi already has a `codec` label on **i2c2**; our WM8960 is on
  **i2c1**, so a distinct `codec_atk` label is used and the stock `&codec` is
  disabled.

### 2.3 Rootfs (Buildroot)

- `BR2_PACKAGE_ALSA_UTILS=y` + `BR2_PACKAGE_ALSA_UTILS_APLAY=y` +
  `BR2_PACKAGE_ALSA_UTILS_AMIXER=y` (ALSA_LIB auto-selected).
- **Boot-time mixer restore**: link `S60alsa-state` → `/etc/init.d/alsa-state`
  and `alsactl -f /var/lib/alsa/asound.state store` (keeps mixer state across
  reboots; `/var` is persistent in this rootfs).

## 3. Debug Journey

| Issue | Root cause | Fix |
|-------|-----------|-----|
| rootfs init failure (stuck shell) | overlay-style `tar xf` lost busybox symlinks (`/sbin/init`, `/sbin/getty`, ...) | `busybox --install -s /sbin` (and /bin, /usr/sbin, /usr/bin) + `ln -sf /bin/busybox /sbin/init` |
| sysvinit choked on busybox inittab | rootfs is busybox-init format but `/sbin/init` pointed to sysvinit | rescue boot: U-Boot `bootargs ... init=/bin/busybox init`; after symlink fix, normal boot works |
| `sdma or sdma firmware not ready` | SDMA=m never loaded; rootfs mounts after probe | `CONFIG_IMX_SDMA=y` + `CONFIG_EXTRA_FIRMWARE` (embedded) |
| `snd_soc_register_card failed` | custom audio-routing widget names (`Mic`, `Line In`) don't exist | use official names: `Mic Jack`, `AMIC`, `Headphone Jack`, `Ext Spk` |
| Silent (card present) | `Left/Right Output Mixer PCM Playback Switch` (numid 52/55) off | `amixer cset numid=52 on; amixer cset numid=55 on` |
| Silent (mixer on) | SAI2_MCLK direction not set → codec has no SYSCLK | verified **IOMUXC_GPR1 (0x020E4004) bit20** controls SAI2 MCLK direction; the stock fsl-sai driver (offset 0x04) sets it automatically |
| aplay stuck (`write error: Interrupted system call`) | playback interrupted (timeout / Ctrl-C) | normal; Ctrl-C resumes the shell |

## 4. Playback Verification

```
$ aplay -l
**** List of PLAYBACK Hardware Devices ****
card 0: atkwm8960 [atk-wm8960], device 0: HiFi wm8960-hifi-0
  Subdevices: 1/1
  Subdevice #0: subdevice #0
card 0: atkwm8960 [atk-wm8960], device 1: HiFi-ASRC-FE (*)

$ amixer cset numid=52 on    # Left Output Mixer PCM
$ amixer cset numid=55 on    # Right Output Mixer PCM
$ amixer sset 'Speaker' 15%

$ aplay /root/test.wav
Playing WAVE '/root/test.wav' : Signed 16 bit Little Endian,
                                Rate 48000 Hz, Stereo
→ speaker sound ✅
```

The mixer state is stored with `alsactl store` and restored at boot by
`S60alsa-state`, so after reboot `aplay test.wav` plays directly.

## 5. Key Takeaways

1. **WM8960 silence checklist**: sound card registered → Output Mixer PCM
   switch → MCLK (GPR1 direction) → volume.
2. **i.MX6UL SAI2 MCLK direction** = IOMUXC_GPR1 (0x020E4004) bit20; the
   fsl-sai driver sets it automatically — do not "fix" the register offset.
3. **SDMA firmware timing**: SDMA probe precedes rootfs mount → embed the
   firmware with `CONFIG_EXTRA_FIRMWARE`.
4. **busybox rootfs symlinks**: overlay tar deployments can silently drop
   symlinks; `busybox --install -s <dir>` rebuilds all applets at once.
5. **NXP `imx6ull-9x9-evk.dts` is the best WM8960 reference** — its SAI2
   (JTAG mux) and I2C1 (UART4 mux) wiring matches the ATK-IMX6U exactly.
6. **WM8960 headphone bypass filter** (R26/C10, R30/C91): shunt to AGND for
   EMI; the 10k resistor also bleeds DC to prevent pop-click.
